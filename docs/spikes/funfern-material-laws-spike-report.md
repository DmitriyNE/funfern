# Material-law validation spike — 19 September 2026

**Historical report; architecture decision now adopted:** the user selected
direct Q,b and the [passive auxiliary boundary](funfern-boundary-auxiliary-spike.md)
with the [scattering follow-up's corrected force-coupled kicks](funfern-boundary-scattering-spike.md).
The [consolidated specification](funfern-material-laws-plan.md) and
[implementation stages](funfern-material-laws-review.md#5-implementation-stages)
supersede this report's pending-review/first-order-only recommendations and next
steps. Recorded measurements and failures below are unchanged. Both outgoing
orders remain required at cutover; performance is measured on the real core.

## Decision

**The bounded spike is complete; the unrestricted architecture gate is not.**
Recommend nodal integrated primary flux `Q` plus independently evolved
quadrature complementary flux `b`. The interior passes the tested linear,
nonlinear, two-sided-loss, interface, energy and convergence cases on funfern's
actual enriched triangles. Pure `ψ,Q` cannot retain the state generated by
spatially varying complementary loss.

However, simply porting the existing second-order outgoing boundary to that
system is **unstable for an admissible complementary-loss case**. The
potential-plus-loss-memory fallback has the same instability. It also adds
cancellation/rebasing problems without removing vector-state transfer work.
Do not start an unrestricted production port on the strength of the interior
results alone.

Recommended review decision: adopt the direct interior, retain passive
first-order outgoing as the initial supported boundary, and require a separately
validated replacement before enabling second-order outgoing with the new core.
This is a proposed scope adjustment, **not yet approved**. Existing scenes must
not silently change outgoing order. If preserving both outgoing orders at
cutover is mandatory, boundary redesign is the next bounded validation task,
before the architecture is frozen. Merely hiding loss controls at the boundary
is not a demonstrated remedy: loss elsewhere can alter the incident state.

The transfer/filter proposal is viable in the small resolved fixtures, not a
proof of general conservative Maxwell remapping. Arbitrary interfaces, newly
exposed cells, and irregular AMR still need explicit acceptance cases.

## Reproduction and scope

Run `bash experiments/material-laws-spike/run.sh` from the repository root.
The [runner and criteria](../../experiments/material-laws-spike/README.md),
[Rust exporter](../../experiments/material-laws-spike/export.rs),
[f64 reference](../../experiments/material-laws-spike/spike.py), and
[captured results](../../experiments/material-laws-spike/results.json) are isolated
from production. A failing numerical check produces exit status 1 after the
complete JSON is emitted; this run deliberately retains failures.

The runner extracts clean core commit
`beca47e0d05c9b24945ef632b00c5cc16f80c8a0` into a fresh temporary directory and
compiles it directly. It exports core mass, stiffness, outgoing operators,
connectivity and the actual enriched-basis gradients. The six quadrature
points/weights mirror the core constants. No Cargo dependency fetch, application,
autosave, or production source edit is involved. The unfinished material-law
work remains as it was; its existing build failures are not repaired here.

Fixtures are structured triangulations of `[-1,1]²`: 4, 8 and 16 squares per side
(32/128/512 triangles and 113/417/1601 enriched nodes). A fourth fixture duplicates
the central seam for split/merge and thin-gap checks. Unit linear coefficients
are used except where stated. Dense eigensolves/projections are **test oracles**,
not proposed live algorithms. Tested with Rust 1.96.0, Python 3.14.6, NumPy 2.5.1.

Acceptance thresholds were recorded before the corresponding measurements in
the experiment README. Additional resolved remap fixtures and factored boundary
histories were added after failures; their results are separate, and the original
failures remain. There are 113 passing checks and six failing checks in the
captured run. The six failures have three explanations, below; they are not six
independent physical defects.

## 1. Interior state, constitutive maps and stepping

Let `C=RG`, `R(x,y)=(-y,x)`, `W` be quadrature integration weights, and `P` the
positive lumped assembled primary constitutive map. The proposed state/equations
are

```text
u = P⁻¹(Q,t)                 v = constitutive_complement⁻¹(b,t)
Q̇ = -η Cᵀ W v - Lp + S      ḃ = η C u - Lc
η = +1 for TM; -1 for TE/Mechanical
```

TM assigns `(u,Q,b,v)` to `(Ez, integrated Dz, B⊥, H⊥)`; TE assigns them to
`(Hz, integrated Bz, D⊥, E⊥)`. Loss channels follow their physical electric or
magnetic field, not whichever field is primary. Nonlinear skin conversion must
convert the complete constitutive map and its actual scalar/vector argument;
reciprocating an additive coefficient slot is not sufficient. These fixtures
check the core argument/sign contract, not the eventual editor conversion code.

At fixed material parameters the discrete energy is

```text
E = Σi ∫₀^Qi P_i⁻¹(z) dz + Σq Wq ∫₀^bq constitutive_complement⁻¹(z) · dz.
```

The `C`/`CᵀW` terms cancel exactly in its time derivative. Time-dependent laws
also contribute material work; this report does not claim energy conservation
under pumping.

For fixed laws, use kick–drift–kick:

```text
Qh = Q - η Δt/2 CᵀW v(b)
b1 = b + η Δt C u(Qh)
Q1 = Qh - η Δt/2 CᵀW v(b1).
```

The reference adds Lie-composed frozen-rate loss. Consequently the complete
lossy method is generally first order, even though its conservative part is
second order. Stage-time drives and source/boundary composition require their
own production-reference tests.

| Check | Result |
| --- | --- |
| Exported core stiffness versus `CᵀWC` | relative residual `2.77e-16` |
| Potential/direct evolution, both signs, 180 steps | relative discrepancy `9.04e-14` |
| Conservative temporal error reduction on halving step | `4.00002` |
| Conservative eigenmode maximum energy excursion, 80 steps to t=0.7 | `0.00375%` |
| Rotated anisotropic energy/operator identity | relative residual `2.66e-16` |
| Kerr/saturable scalar and radial-vector inverse residuals | below `3.6e-16` |
| Both-side nonlinear final energy error, 60 small steps | below `0.00176%` |
| Two-channel passive loss and electric/magnetic duality | pass on tested rates |
| Heterogeneous weak interface equilibrium / energy cancellation | below `1.8e-15` |

The anisotropy check derives the rotation `R A Rᵀ` from the gradient-form tensor;
it is not an end-to-end test of every production anisotropic material assembler.
Kerr is `f(u)=u(1+0.8u²)` and saturable is
`f(u)=u[1+0.8u²/(1+u²)]`. Inversion uses deliberately conservative f64 bisection,
not a GPU iteration-budget benchmark.

On the smallest mesh, `b` has 384 scalar degrees of freedom, `rank(C)=112`, and
272 force-invisible stationary directions. After spatial loss alone, a compatible
field has a **3.60% weighted-norm component outside the potential image** in the
tested fixture. Some such state is physical loss-generated charge/static
response. A blanket projection back to `Cψ` would change the requested physics.
Conversely, numerical stationary errors will not leave as outgoing waves.

## 2. Boundaries and physical auxiliary state

### First-order outgoing: supported candidate

For the unit linear exterior, append `-D u` to `Q̇`, with exported nonnegative
lumped boundary damping `D`. Its energy contribution is `-uᵀD u ≤ 0` and it
requires no potential history. For a physical impedance law, the analogous
coefficient must be derived from the exterior constitutive response; the unit
fixture does not validate arbitrary nonlinear radiation impedance.

The actual direct-state spectrum is non-growing for `(γp,γc)=(0,0), (0.4,0.9),
(0,4)`. The largest real parts are approximately `8.4e-15`, `-0.6602`, `-0.9372`.

### Existing second-order outgoing: failed unrestricted migration

The exported old scalar boundary gives

```text
M ü + D u̇ + K u + A z = 0,      ż = u.
```

An equivalent direct-state extension, in the compatible lossless limit, is

```text
Q̇ = -CᵀW b - D u - A r,         ḃ = C u,
ṗ = u|boundary,                  ṙ = p.
```

Differentiating the first equation recovers the old scalar equation. The
derivative comparison residual is `2.36e-16`. These are two boundary histories,
not a replacement bulk potential. An equivalent factorization `A=BᵀB` stores
trace-gradient histories `ẋ=B u, ẏ=x` and uses force `-Bᵀy`; a local edge
gradient/quadrature factor is suitable for production. The dense factorization
in the spectral oracle only removes irrelevant constant histories.

The impedance is `Y(s)=D+A/s²`; at `s=iω`, `Y=D-A/ω²` is not necessarily
nonnegative. Hence this truncation has no unconditional passive-port guarantee.

With complementary loss `ḃ=C u-4b`, primary loss zero, an eigenvalue is
**`0.0461825 ± 0.981290 i`**. Its normalized eigen-residual is `8.5e-17` and the
growth remains after factoring away constant boundary histories. The e-folding
time is about 21.7 simulation time units: a short good-looking packet run is not
a stability certificate. These are two of the six recorded failed checks (raw
and factored representations of the same physical failure).

Two other failed checks are near-zero positive roots around `8–9e-8` in the
redundant `p,r` representation. They disappear with trace-gradient histories:
the corresponding factored growth rates are `1.34e-14` and `-0.02892`. They
diagnose ill-conditioned redundant memory eigenproblems, **not established
physical growing modes**. Thresholds were not relaxed to hide them.

Packet tests use 512 triangles, wavelength 0.65, a localized travelling Gaussian,
560 RK4 steps to t=2.6, and reflecting runs as controls. Residual bulk-energy
amplitude proxies are:

| Incidence | First order | Second order |
| --- | --- | --- |
| 0° | 2.55% | 3.33% |
| 30° | 5.23% | 6.30% |

These meet the declared packet thresholds; they do not establish that second
order is better, or measure pure plane-wave reflection. RK4 isolates boundary
feasibility; the eventual KDK/loss/boundary composition is not validated here.

### Thin gaps and prescribed boundaries

For paired trace jump operator `T`, keep physical gap state `z`:

```text
ż = T u,       Q̇gap = -Tᵀ Kg z,       Egap = zᵀ Kg z / 2.
```

Positive paired Simpson weights yield exact opposing total forces and cancelling
energy exchange. Nine trace degrees of freedom reproduce compatible scalar
potential evolution to `3.28e-15` over 100 steps. This is a straight-seam model
using existing enriched nodes, not a test of the production gap assembler or
every curved/nonmatching trace. Gap state needs its own transfer and diagnostics;
bulk `b` cannot reconstruct it after arbitrary loss/history.

During a material edit on prescribed `u=g`, set `Qnew=Pnew(g)` and account
`ΔQ=Qnew-Qold` as external boundary exchange; free-node `Q` stays unchanged.
The simple nonzero prescribed-field fixture passes. This must extend to the
complete event transaction, not become an unaccounted post-commit overwrite.

## 3. Filter and remapping

### Paired linear wave filter

With `K=CᵀWC`, a bound `λ ≥ λmax(M⁻¹/² K M⁻¹/²)`, and `0≤α≤1`, use

```text
Q ← Q - α K M⁻¹ K M⁻¹ Q / λ²
b ← b - α C M⁻¹ K M⁻¹ CᵀW b / λ².
```

A coupled mode of squared frequency `λj` is multiplied by
`1-α(λj/λ)²` on both sides. Constants, free-component primary totals and
`ker(CᵀW)` are preserved. At `α=0.8`, the top mode loses 80% amplitude, while
the tested mode at 8.52% of the frequency ceiling loses only 0.00422%.

The prototype uses the exact spectral ceiling. Production needs a conservative
cheap bound, finite-precision invariant tests and an explicit cadence. This
filter costs multiple gather/operator applications when invoked; no free
per-timestep filter is assumed. Nonlinear/material-variable generalization is
not established by the unit linear test.

### Local transfer candidate and its limits

Interpolate primary density `Q/geometric_support`, re-integrate against the
target geometric supports, then correct the affected free support to its
required total. Opening a seam partitions old integrated support; closing it
sums the shares. Prescribed-support changes enter the external exchange ledger.
Material coefficients must not be confused with geometric support.

For `b`, fit a degree-two vector polynomial to each source triangle's six
quadrature samples and evaluate it at target quadrature points. Geometry-only
owner/weight stencils can be prepared in advance and evaluated on the latest
GPU state. This avoids a global potential recovery and a live CPU field round
trip. Exact unchanged samples should copy directly. The fixture performs a full
remesh, so all support is eligible for the primary correction; it does not
justify a global correction during a local edit.

Integrated primary totals agree within `4.5e-16`; constant/affine reproduction is
within `3e-15`. Split–merge recovers primary and vector state and the next time
step within `3e-15`, without a potential-gauge alignment solve.

| Transfer | Vector weighted RMS versus analytic field | Stationary vector-energy fraction |
| --- | --- | --- |
| 4→4 squares/side | 5.817% — failed 5% criterion | roundoff |
| 4→8 | 5.814% — failed 5% criterion | roundoff |
| 8→4 | 1.523% | 0.292% |
| 8→16 | 1.485% | roundoff upper bound |
| 16→8 | 0.383% | 0.0222% |

The first two are the remaining two recorded failed checks. The coarse source
already has 5.817% differentiated-field error before transfer; identity preserves
it and refinement cannot recover missing information. They are under-resolution
failures against the analytic-field criterion, not evidence that identity
transfer changes the vector state. The finer cases were added to separate these
effects; no threshold was raised.

After twelve 8→4→8 cycles, vector change from the initial discrete field is
2.19% and stationary energy is 0.0295%. These artifacts can persist under the
wave filter. Weighted projection onto the potential image is used **only to
measure them**, not as a proposed correction. Element-interior divergence is
also reported, but excludes face jumps; it is not a complete discrete Gauss-law
or interface-charge audit.

For this toy, local polynomial transfer with explicit error/charge diagnostics
is a reasonable candidate. Before cutover it still needs irregular meshes,
one-sided discontinuities, partial affected-support corrections, new-cell
extension, nontrivial multiway joins and f32 cycling. Reject an edit when its
validated transfer contract cannot be met. Do not erase all stationary modes to
make a diagnostic look clean.

## 4. Cheap policies and fallback comparison

At a nonlinear material junction, loss must use the assembled effective rate,
not an arithmetic average of constituent rates. The fixture
`P(u)=u+0.8u³`, `L(u)=0.2u+1.4·0.8u³` uses
`Qnew=Q exp[-Δt L(u)/Q]`. Error versus a refined reference at Δt=0.01 is
0.094%, decreasing by a factor 2.05 when Δt halves. The rate varies from 0.210
at u=0.1 to 0.842 at u=1.2 despite constant constituent rates. Positive radial
decay decreases the tested convex constitutive energies. This does not license
the same radial shortcut for arbitrary anisotropic loss.

For old acceleration `a(t)=a₀+A sin(ωt+φ)`, the migrated direct rate is

```text
r(t)=a₀t + A t sinc(ωt/2) sin(φ+ωt/2),   sinc(z)=sin(z)/z.
```

Its derivative/zero-frequency limit checks pass down to ω=0 and 1e-14. A source
edit uses the current carrier/analytic waveform and an explicit normalization,
not a spatial trail of prior source locations. This algebra does not claim exact
reproduction of old startup transients or validate final UI/source units.

Per-drive phase anchors preserve phase at the frequency-edit boundary in f64;
the epoch test uses t=2²⁶. Reversing a smootherstep ramp restarts from its current
value and includes that value in the new admissible envelope. Derivative
continuity is intentionally not promised. The GPU's split clock, frozen
run-start source envelope and paused-event service still need implementation
tests.

The candidate/validate/commit CPU model preserves accepted fields, clock,
accounting and serial on injected rejection. These are small ownership
fixtures, **not GPU synchronization tests**; they do not implement all inverse,
pulse or law-patch failure paths. Near-threshold saturable and bounded-domain
inverse fixtures cover some fault prevention, not all nonlinear material laws.

The fallback `b=Cψ+z`, `ψ̇=u`, `ż=-γc b` reproduces the failed boundary
eigenmode: lifting the unstable eigenvector gives a loss-memory equation
residual `4.60e-13`. Changing representation cannot repair that boundary law.
For a manufactured held-gradient state, `Cψ` grows while `b` remains bounded;
at t=2²⁶, reconstructing a true flux 0.25 from two f32 terms gives zero, whereas
direct storage retains 0.25. This is an algebraic long-clock counterexample,
not a long-duration GPU run; coordinated rebasing would be required.

On one spatial-loss/remap fixture, direct and potential-plus-memory transfers
differ by 7.37% in weighted norm. Their stationary-energy fractions are 1.31%
and 1.04%, respectively; **neither is a failure of the zero-artificial-charge
criterion**, because this input already contains physical nonpotential loss
state. No evidence makes the fallback preferable enough to pay its added
state/rebasing cost. It requires at least another accepted/candidate scalar
potential pair (`8N` bytes in f32), plus any rebasing scratch, while retaining
the vector memory and its remapping.

## 5. Provisional GPU resource design

This is a packing/accounting feasibility screen, not a compiled shader or
measured GPU allocation/throughput result. The existing Rust/WGSL packing gives
main baseline bytes `240N + 4(N+1) + 12nnz`: node metadata 176, state 48 and
source-membership words 16 bytes per node, plus CSR. The old core estimate
undercounts that packing and must not be used as the comparison denominator.

Candidate storage budget:

| Part | f32/integer bytes |
| --- | --- |
| Retained node metadata | `176N` |
| Accepted/candidate Q, primary scratch and accounting allowance | `16N` |
| Source words and incidence ranges | `24N` |
| Accepted/candidate b, 6 quadrature × 2 components | `96E` |
| Connectivity and affine element geometry | `64E` |
| Quadrature constitutive metadata/index records | `192E` |
| Seven primary contribution records, 16 bytes each | `112E` |
| Local seven-node force scratch and deterministic node incidence | `88E` |
| Accepted/candidate boundary auxiliary allowance | `32Nb` |

Thus `216N+552E+32Nb`: 43,096 bytes versus baseline 42,180 on the small mesh;
632,536 versus 614,916 on the packet mesh (1.022× and 1.029×). These counts
include primary material-instance records: there is no fixed maximum number
of incident material contributions per node.

Prepared transfer stencils budget `96Nnew+192Enew`: the vector term is six
32-byte records per target element, each with source-element ID, six weights
and padding. Primary accounting/reduction scratch reserves another `16Nnew`.
Equal packet-sized old/new generations therefore need about **1,542,688 bytes**
for these main buffers/stencils/reductions during handoff, before shared data.
More elaborate component correspondence/extension metadata remains additional.

Shared source payloads, constitutive formula/law catalogue tables, display,
recorders and readback pools are excluded from both main totals. A provisional
linear law record can be one 64-byte block (reference/tensor/loss fields and
IDs); nonlinear coefficients, expression bytecode, parameters and each drive's
accepted/candidate anchors/ramp state are variable-capacity tables and are **not
certified by the 1.03× figure**. Likewise gap trace state is additional: at least
8 bytes per trace for accepted/candidate z, plus geometry/weight/incidence
records. Final per-law/trace layouts and peak limits must be tested before GPU
implementation; current evidence rules out no architecture on main-state size.

Eight storage bindings can be packed as control/status/clock; nodal metadata
and contributions; element geometry/quad laws; node incidence; nodal state;
vector state; local-force scratch; sources/events/law runtime. Stage-specific
bindings can substitute transfer/gap tables. Aliasing accepted/candidate ranges
within one storage buffer does not permit early accepted-state writes.

Conservative stepping needs approximately three field dispatches (half kick,
drift/local force, final gather/kick) plus a globally ordered acceptance dispatch,
with one or two additional element passes for unfused loss. A pre-drift cached
force is reusable only when its law/state generation matches. All writers stage
their state and auxiliaries; validation sets a shared failure flag, then a later
dispatch copies/accepts **all or none**, including clock and accounting. One
workgroup barrier cannot establish this global boundary.

NumPy packet timings are about 104 µs for a CSR force, 248 µs for vector-force
gather and 705 µs for a complete direct step. These compare neither complete
old/new GPU timesteps nor optimized Rust code. Direct flux must not inherit a
claim of the old one-CSR fast path. A small GPU prototype is appropriate before
cutover if measured throughput becomes a go/no-go issue; the current decisive
failure is mathematical, not hardware-dependent.

## 6. Required plan reconciliation and next steps

The existing implementation stages remain gated pending review. On approval of
the direct candidate and an outgoing-boundary policy:

1. Freeze `(Q,b, physical trace/oscillator state)` and remove **bulk potential**
   gauge/seam-offset/rebasing obligations from direct-state stages. Retain any
   genuine oscillator/trace reference requirement; those are not bulk gauge.
2. Use the direct-state equations and linear filter/transfer reference above.
   Finish the unresolved boundary decision and targeted remap fixtures **before
   production cutover**, not after enabling the new solver.
3. Restore inert authoring infrastructure, preserving the previously reviewed
   reusable law/schema work; the spike adds no new reason to discard it. Fix its
   existing import/literal/persistence gaps during the planned stage, not here.
4. Build the proper CPU reference: source units, KDK/boundary/loss composition,
   physical gap assembly, all legacy boundary meanings, f32 validity tolerances,
   and supported anisotropic/nonlinear contracts. The isolated oracle is not a
   drop-in solver.
5. Freeze actual GPU layouts including variable law/trace capacity, then test
   staged failure/commit and latest-state remapping. Port AMR residuals, gap
   diagnostics, energy/flow, rendering and probes explicitly to `Q,b`.
6. Only then enable the common production core and proceed with time drives,
   nonlinear catalogue and Simplified/Advanced editor work.

No production code, user scenes, autosaves or existing unfinished material-law
changes were modified. No commit or deployment was made. The narrow decision
now needed is whether first-order outgoing is acceptable for the initial new
core, or whether a validated higher-order boundary remains a cutover requirement.
